## 信息与状态规则

- 版本栏永远预留两层：上方“当前：…”或“待部署版本”，下方选择框。长文本单行省略，提示与详情可查看全文。状态区最多两行，不能用无限换行撑高行。
- 当前版本不可重复换版、没有其他版本、来源失联等原因必须继续提供给鼠标悬停、键盘焦点及辅助技术；不能只留下无原因的灰按钮。真正执行前的错误仍保留现有预检。
- 窄宽度按整张表的可用宽度切换；如果三按钮放不下，整组移到下一行，并让同表所有资源行同步使用更高行高。不得只让已部署项增长。长名称、英文以及 125%/150%/175% 缩放须用实际窗口验证，80 px 为普通密度样板值，不允许裁切文字或按钮硬凑高度。
- 资源库版本行采用“查看 / 移除版本 / 打开资源目录”一组同排操作；被引用版本的移除禁用规则不变。
- 设置页保护区顶部“打开副本目录”打开总目录，每条“打开此副本”打开原有单次版本副本目录；名称变化不改变路径。统计、时间、游戏/库/版本和部署路径保留，长路径省略并提供全文。
- 常规保存不改变语义；制作离线表单仍保留 EXE、位数、API、输出目录、新文件夹名称、重置和制作。按钮位置固定，状态提示预留区域。没有输入时制作禁用，成功/错误内容在同一区域显示。
- 保护副本零条时列表区域显示“暂无修改保护副本”；读取中/失败只更新该区域；多条记录沿用页面滚动，不新增分页或筛选功能。
- 设置页窄窗口按常规、应用数据、保护副本、离线制作顺序上下排列，沿用既有行为。
