# r11 重复提示核查

用户已确认：离线制作成功提示只保留结果区的一处，检查并消除同类重复。本轮不新增功能或更改部署/制作规则。

## 保留的结构

沿用 r8 设置分类、正文宽度、公共卡片和原生按钮。离线表单校验槽仍为 72 DIP，成功时清空文字，错误原位显示；重置/制作按钮尺寸、位置不因成功提示隐藏而跳动。结果区保留成功状态、输出路径、后续步骤和打开文件夹。局部样板为 `visuals/offline-feedback-r11.svg`，说明文字仅用于设计记录。

## 已核查的重复

- `OfflinePreparation.Check` 和结果区同时显示 `OfflineReady`：保留结果区，校验区成功时为空。
- 离线页 `OfflinePageSummary` 与 `OfflineHelp` 都说明提取 DLL、不运行安装器：保留页首说明，帮助只保留位数/API、Vulkan 范围和手动补充资源要求。
- 游戏页 `PreflightHelp` 与 `BatchSelectionHelp` 都说明取消勾选不清除部署：保留表格上方说明，批量区只说明计数和预检。
- 游戏的已部署/核对状态、资源库的来源可用/引用游戏分别表达不同事实，保留。
- 设置常规、保护副本、数据迁移、启动、通用表单、任务结果弹窗没有找到同一成功提示双写；任务结果已按状态/详情相同文本去重。不同任务的独立状态不合并。

直接复用现有 WinUI `Ui.Status`、本地化资源键、表单与结果区域；没有新增依赖或数据模型。扩展已有 GitHub 离线 UI 检查：中英文成功文字计数为 1、重置后为 0、目录冲突提示仍为 1、按钮在卡片内位置不变。使用真实截图核对样板；本地仅静态检查。
