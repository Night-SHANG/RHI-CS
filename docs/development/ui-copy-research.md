## RHI-CS 当前问题

- `TargetRelative`、`TargetOverride` 把字段名称、留空规则和页面关系塞在同一个长标题中。
- `LibraryExplanation`、`ConfigOnly`、`FormReady` 等多次解释“保存不会部署”，`VersionSourceHelp` 又补充源文件不变。正常表单中的有效反馈也长期占用说明空间。
- `VersionTargetHelp` 同时承担继承规则、当前结果、输入示例、完整路径限制、自动创建说明，信息过密。
- 保护相关文字混用“修改副本”“保护副本”“保护目录”。需要区分对象后统一命名，不能将不同的备份用途合并。
- 用户已经确认：版本留空沿用资源库设置，只有资源库也为空时才使用游戏页部署目录。任何精简都必须保留这个区别。

核查依据为当前 `src/Rhi.App/Strings/{zh-CN,en-US}/Resources.resw`、`Pages/LibrariesView.cs` 和 `Presentation/Forms/ValidatedForm.cs`，不以旧样板文字代替实现。

## 推荐用语

| 位置/概念 | 建议名称 | 必要的一行说明 |
| --- | --- | --- |
| 游戏页完整目标路径 | 部署目录 | 使用完整路径，并可浏览选择。 |
| 添加资源库的目标字段 | 部署子目录 | 留空使用游戏部署目录。 |
| 添加版本的目标字段 | 部署子目录 | 留空沿用资源库设置。 |
| 版本来源 | 资源文件目录 | 保留用户指定名称；按钮区分“选择文件夹”和“选择文件”。 |
| 版本标签 | 版本名称 | 不引入版本号格式限制。 |
| 配置动作 | 添加资源库、添加版本、保存 | 保持现有含义，不称为安装或导入。 |
| 文件写入动作 | 部署、更换版本、清除部署 | 与删除库记录、删除来源文件严格区分。 |
| 原先已有文件的留存 | 原件备份 | 与后续用户修改的保护副本分开。 |
| 后续用户修改的留存 | 修改保护副本 | 设置、提示、结果页保持同名；不笼统缩为“备份”。 |

“部署目录”表示游戏页选定的完整目录；“部署子目录”表示其内部路径，例如 `mods\textures`。这是表达建议，不改变已有路径类型、安全限制和空值含义。

版本路径为空时，可以用一行持续可见的提示表达规则及当前结果：

- 资源库也为空：`沿用资源库：游戏部署目录`。
- 资源库填写 `mods`：`沿用资源库：游戏部署目录\mods`。
- 版本填写 `mods\textures`：`部署位置：游戏部署目录\mods\textures`。

前两项明确说明继承关系；不能只显示最终位置。资源库和版本未绑定具体游戏时，“游戏部署目录”是规则描述，不应编造实际盘符。具体游戏的完整目标路径仍在操作预览阶段展示。

## 信息保留位置

- 页面常驻：名称、路径、状态、操作按钮。引导“先添加资源库，再添加版本”适合空列表状态，不必在有内容的页面反复展示。
- 字段常驻：留空规则和来源/目标区别；需要时显示一条结果说明。关键规则不能只藏在悬停提示里，也不能仅依靠输入后消失的占位文字。
- 就近帮助：路径示例、文件夹自动创建的时机、复制文件夹内容还是文件夹本身。优先减少现有重复文案；如需新增可展开帮助控件，应另按 UI 流程制作样板，不在调研中默认为已授权实现。
- 正常反馈：无需持续显示“输入有效、提交再核对”等内部校验过程。保存按钮是否可用及明确的错误提示已经承担主要反馈；删除提示后还需复核无障碍及布局稳定性。
- 风险步骤：覆盖、保护副本、清除、恢复影响必须在相应预览/确认中清楚显示，不为了简短删掉数据影响。
- 常规保存说明：若仍需要，只保留一句“保存不会部署文件”，不在同一界面重复出现。

## 错误提示示例

以下为表达建议，不能假装现有校验已能识别比错误码更具体的原因。

| 场景 | 建议提示 |
| --- | --- |
| 把完整路径填进部署子目录 | 此处填写游戏目录下的路径，例如 mods。资源来源请在“资源文件目录”中选择。 |
| 来源不存在 | 找不到资源，请重新选择文件或文件夹。 |
| 来源与数据目录重叠 | 资源不能与数据目录重叠，请选择独立目录。 |
| 来源与游戏目录重叠 | 资源不能与游戏目录重叠，请选择独立目录。 |
| 非法子目录输入 | 路径格式无效，请使用 mods 或 mods\textures 这样的路径。 |

保留可核对的出错路径和必要详情，避免只留下“操作失败”。针对保留名称或具体非法字符的精准提示，需要先确认错误码能区分，再实施；不把推测写进提示。

## 建议实施边界

资源库及版本表单去除重复说明，同批统一游戏、设置、错误和保护副本用语。继续使用现有双语资源和共享表单，不增设资源类型、不改继承关系、不改部署/备份/恢复行为。正常表单不显示校验过程文字，错误区保留高度；关键风险仍在确认步骤呈现。视觉依据为 `docs/design/visuals/library-path-forms.svg`，本次更新短标签与就近规则，不改变统一组件和底部按钮位置。
